    Download the app

    Tap the button below on your Android phone.

    Allow the install

    Android asks once whether your browser may install apps. Allow it, then tap Install.

  3. 3

    Open Motio

    Create your account and allow location and activity, so trips are recorded on their own.

Why does Android warn me?

Motio isn't on Google Play yet, so Android asks before it installs an app from outside the store. The file comes straight from Motio's release page on GitHub, signed with Motio's own key, and has no ads. After that, new versions arrive inside the app.
